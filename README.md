# Python-Assignment-2-Data-Structures-List-Dictionary-Operators-Conditional-Statements

## Topics Covered

### 1. Lists
- Creating lists of integers and strings
- Adding and inserting elements
- Removing and popping elements
- Extending and sorting lists
- Finding the maximum, minimum, and sum of values
- Accessing list elements using indexing and slicing
- Reversing a list

### 2. Dictionaries
- Creating a dictionary of student marks
- Accessing values using keys
- Adding new key-value pairs
- Updating existing values
- Using `keys()`, `values()`, and `items()`

### 3. Sets
- Creating sets and understanding the important character-duplicate removal
- Understanding why set elements cannot be accessed by index or modified by index
- Finding the union and intersection of two sets

### 4. Operators and Conditional Statements
- Accepting a score from the user
- Categorizing performance using `if`, `elif`, and `else`
- Displaying a suitable message for the score category


## Skills Practiced
- Python fundamentals
- Data structures: lists, dictionaries, and sets
- Indexing and slicing
- Built-in methods
- Conditional logic
- User input and output


## Learning Outcome
This assignment provides practice in creating and manipulating Python data structures and using conditional statements to make decisions based on user input.
